# 🗺️ CampusGuide

> 교내 시설과 건물 정보를 한눈에 확인할 수 있는 캠퍼스 안내 서비스

학생들이 학교생활 중 필요한 시설을 쉽고 빠르게 찾을 수 있도록 제작한 교내 캠퍼스 맵 프로젝트입니다.

---

## 📌 프로젝트 소개

기존 교내 캠퍼스 맵을 이용하면서 **시설물의 위치나 상세 정보가 충분히 표시되지 않아 원하는 장소를 찾기 어려운 점**을 개선하고자 시작한 프로젝트입니다.

건물의 위치뿐만 아니라 학생들이 실제 학교생활에서 자주 이용하는 **편의시설과 주요 시설의 위치 및 정보를 함께 제공**하여 캠퍼스를 처음 이용하는 학생도 필요한 장소를 쉽게 찾을 수 있도록 구현했습니다.

---

## 🎯 개발 배경

기존 캠퍼스 맵을 사용하면서 다음과 같은 불편함을 느꼈습니다.

* 건물 위주의 정보만 제공되어 필요한 시설을 찾기 어려움
* 교내 편의시설의 위치를 한눈에 확인하기 어려움
* 원하는 시설을 찾기 위해 직접 학교 곳곳을 확인해야 하는 불편함

이러한 문제를 해결하기 위해 **학생이 실제 학교생활에서 자주 찾는 시설을 중심으로 정보를 제공하는 캠퍼스 안내 서비스**를 제작했습니다.

## ✨ 주요 기능

### 🏫 건물 및 시설 정보

* 교내 건물 위치 확인
* 건물별 상세 정보 제공
* 건물 내부 주요 시설 및 편의시설 정보 제공

### 🔎 시설 검색 및 필터링

* 원하는 건물 및 시설 검색
* 시설 종류에 따른 필터링
* 지도와 목록을 연동하여 위치 확인

### 🗺️ 캠퍼스 지도

* 교내 건물 및 시설 위치 표시
* 지도에서 시설 선택 시 상세 정보 확인
* PC와 모바일 환경을 고려한 반응형 화면 구성

## 🛠 기술 스택

### Frontend

* **HTML5** — 웹 페이지 구조 및 콘텐츠 구성
* **CSS3** — UI 및 반응형 레이아웃 구현
* **JavaScript** — 지도, 검색, 필터링 및 사용자 인터랙션 구현

### Backend

* **Node.js** — 서버 실행 환경
* **Express** — REST API 및 서버 구현

### Database

* **MySQL** — 건물 및 시설 정보 데이터 관리

---

## 🏗️ 시스템 구성

```text
사용자
  │
  ▼
HTML / CSS / JavaScript
  │
  │ HTTP 요청
  ▼
Node.js + Express
  │
  │ SQL
  ▼
MySQL
```

프론트엔드에서 사용자의 검색 및 시설 선택 요청을 처리하고, Express 서버를 통해 MySQL에 저장된 건물 및 시설 정보를 조회하여 제공합니다.

---

## 💡 주요 구현 내용

### REST API를 이용한 데이터 처리

Express를 이용하여 건물 및 시설 정보를 API 형태로 제공하도록 구현했습니다.

```text
Client
   │
   │ GET /api/...
   ▼
Express Server
   │
   │ SQL Query
   ▼
MySQL
   │
   ▼
시설 및 건물 정보 반환
```

### 데이터베이스 기반 시설 관리

건물과 시설 정보를 코드에 직접 작성하는 방식이 아닌 **MySQL 데이터베이스에 저장하여 관리**하도록 구성했습니다.

이를 통해 시설 정보가 변경되거나 새로운 시설이 추가될 경우 데이터를 수정하여 반영할 수 있도록 했습니다.

## 📚 배운 점

### 프로젝트 당시

처음 개인 프로젝트를 해보며 **프론트엔드와 백엔드, 데이터베이스가 연결되어 하나의 서비스로 동작하는 과정**을 경험했습니다.

특히 JavaScript에서 발생한 요청을 Express 서버에서 처리하고, MySQL의 데이터를 조회하여 다시 사용자에게 전달하는 과정을 직접 구현하면서 **웹 서비스의 전체적인 데이터 흐름**을 이해할 수 있었습니다.

또한 실제 사용자의 입장에서 기존 서비스의 불편한 점을 찾아보고, 이를 기능으로 구체화하는 과정을 경험했습니다.
